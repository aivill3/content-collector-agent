# 구현 결과 보고 — 콘텐츠 수집 Agent Prototype

진입: `Content Collector App.dc.html` (해시 라우팅 `#/<화면 ID>?id=…` — 브라우저 뒤로가기 지원)
구조: UI(`*Screen.dc.html`) → Service(`services/api.js`, Mock) → Mock Data(`mock/data.js`)
기술 스택 메모: 요청 기준은 React/Next.js/TS/Tailwind이나, 이 환경은 Design Component(React 런타임, 인라인 스타일) 형식으로 구현함. 실제 코드베이스 이식 시 화면 단위(DC 1개 = 페이지 1개)로 대응됨. [확인 필요]

## 주요 기능
| 기능 ID | 구현 |
|---|---|
| FN-AUTH-001 | 필수 검증, 로딩/비활성, 실패 배너(U03) |
| FN-COL-001 | 대기 → 실행 중 → 성공/실패, 작업 이력·소스 상태 동기 갱신, UI 중복 클릭 방지 |
| FN-CNT-001/002 | 검색·소스·기간·관련도 필터, 스쳐 지나감 흐리게/숨김(설정 연동), 페이지, CSV |
| FN-CNT-004/006/007 | 제거 구간 주황 표시, 복사, 단건 재분석 |
| FN-SRC-002~010 | 키워드 추가/삭제, 검색 테스트, 자동 탐지·후보 선택, 수동 5단계 선택, URL 확인, 저장/저장 후 수집/취소(미저장 확인) |
| FN-JOB-001~004 | 필터, 행 펼침(단계별 건수/실패 사유), 조치 버튼, CSV |
| FN-ANL-001~007 | 순위(불용어 즉시 제외), 적중도, 연관어 → 검색 키워드/불용어/글 보기, 추이 30·90일 |
| FN-SET-001~007 | 범위, 프리셋, 허용 범위 검증(ADMIN-001-U06), 실시간 변경 미리보기, 저장/초기화 |
| FN-DIC-001~006 | 추가·붙여넣기·CSV 가져오기/내보내기, 필터·정렬, 토글, 선택 삭제, 미반영/재분석 |
| FN-ADM-001~007 | 지표, 기본값 편집(검증), 공통 불용어 추가·삭제(사전과 연동) |
